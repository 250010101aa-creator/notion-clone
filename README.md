# Notion Clone

Personal Notion-like app: hierarchical pages, block editor, databases.

## Start

```bash
npm run dev
```

Opens on http://localhost:5173 (client) + http://localhost:3001 (API).

## Features

- **Pages** — create, rename, delete, nest (sidebar tree)
- **Block editor** — type `/` for heading, bullets, todo, code, quote, image, divider
- **Databases** — add typed columns (text/number/date/checkbox/select), add/edit/delete rows
- **Auto-save** — blocks save 1s after last change

## Requirements

Node.js 18+
